Clean up audit records that are older than the retention period configured for the
Deploy Engine instance.

The default retention period for audit records is considerably longer than for the
other categories of state, because an audit trail is of interest precisely when
something is being looked into after the fact.

Removing records from the trail is itself an action taken through the engine, so it is
recorded in the trail like any other.
